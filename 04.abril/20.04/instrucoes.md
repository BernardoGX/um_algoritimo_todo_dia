Desafio: Crie um script que receba uma senha do usuário e valide se ela é forte. Regras: deve ter no mínimo 8 caracteres, conter pelo menos um número e uma letra maiúscula. O programa deve retornar "Senha aprovada" ou listar os requisitos que faltaram.

Exemplos de saida esperada:

Caso 1 (senha aprovada):
=== Validador de Senha Forte ===
Digite uma senha para validar: Senha123
Senha aprovada

Caso 2 (senha reprovada):
=== Validador de Senha Forte ===
Digite uma senha para validar: abc
A senha nao foi aprovada. Faltou atender:
- Ter no minimo 8 caracteres
- Conter pelo menos um numero
- Conter pelo menos uma letra maiuscula
